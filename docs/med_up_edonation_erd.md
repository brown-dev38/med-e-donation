# ER Diagram — MED UP e-Donation

เปิดไฟล์ [med_up_edonation_erd.drawio](med_up_edonation_erd.drawio) ด้วย Draw.io ใน VS Code หรือ diagrams.net ผ่าน **File → Open From → Device** แล้วเลือกแท็บด้านล่างเพื่อเปลี่ยนหน้า

| หน้า | เนื้อหา |
| --- | --- |
| 01 ภาพรวม ERD | ทั้ง 12 ตาราง พร้อม 16 Foreign Keys และความสัมพันธ์เชิงตรรกะของเลขอ้างอิง |
| 02 การบริจาคและใบอนุโมทนาบัตร | ฟิลด์ทั้งหมดของกองทุน การบริจาค ใบอนุโมทนาบัตร การแจ้งเตือน และผู้ดูแล |
| 03 ส่งออกและติดตามผล | รอบส่งออก รายการในรอบ การติดต่อเจ้าหน้าที่ และ Audit Log |
| 04 จัดการหน้าเว็บไซต์ | การตั้งค่าหน้าแรก ข่าวประชาสัมพันธ์ และสไลด์แบนเนอร์ |

ตาราง ฟิลด์ และเส้นเชื่อมแก้ไขได้ใน Draw.io โดยเส้นเชื่อมผูกกับแถวคีย์ที่เกี่ยวข้อง แสดง PK, FK, UQ, ชนิดข้อมูล และการอนุญาต NULL ฟิลด์ทั้งหมด 134 ฟิลด์แสดงครบในหน้ารายละเอียด ตารางที่แสดงซ้ำในแต่ละหน้าคือตารางเดียวกัน

สัญลักษณ์ Crow’s Foot ใช้ `1` = หนึ่งรายการ, `0..1` = ศูนย์หรือหนึ่งรายการ และ `0..*` = ศูนย์หรือหลายรายการ เส้นทึบแสดง Foreign Key ส่วนเส้นประสีม่วงแสดงการอ้างอิงเชิงตรรกะที่ SQL ยังไม่ได้บังคับด้วย FK

แผนภาพยึด `CREATE TABLE` ใน [เอกสารออกแบบฐานข้อมูล](med_up_edonation_database_design%20%281%29.md) เป็นหลัก และตรวจประกอบกับ [flow.md](flow.md) โดยมีข้อสังเกตจากเอกสารเดิมดังนี้:

- SQL มี 12 ตาราง รวม `admin_notifications` ซึ่งยังไม่มีในรายการภาพรวม 11 ตารางเดิม
- `donations.verified_by` / `verified_at` มีใน Data Dictionary แต่ไม่มีใน DDL แผนภาพจึงใช้ `slip_verified_by` / `slip_verified_at` และ `rd_submitted_by` / `rd_submitted_at` ตาม DDL
- `pr_news_articles.updated_by` และ `created_at` มีใน DDL จึงแสดงในแผนภาพด้วย
- `contact_inquiries.reference_no` ไม่มี FK ไปยัง `donations.reference_no` จึงแสดงด้วยเส้นประ ส่วน `audit_logs.target_table` / `target_id` เป็นการอ้างอิงหลายชนิดตารางและไม่มี FK ไปยังตารางเป้าหมาย
- `acknowledgement_certificates.donation_id` เป็น UNIQUE จึงมีใบอนุโมทนาบัตรได้สูงสุดหนึ่งใบต่อการบริจาคหนึ่งรายการ และมี UNIQUE เพิ่มที่ `(fiscal_year_be, running_seq)`
- การบริจาคและรอบส่งออกมีความสัมพันธ์ M:N ผ่าน `edonation_export_items` โดย UNIQUE `(batch_id, donation_id)` ป้องกันซ้ำเฉพาะภายในรอบเดียว ยังอนุญาตให้รายการบริจาคเดียวกันอยู่ในหลายรอบ

ไฟล์นี้บันทึกโครงสร้างตามเอกสารต้นฉบับ ไม่ได้แก้ไข schema หรือ SQL ของโครงการ
